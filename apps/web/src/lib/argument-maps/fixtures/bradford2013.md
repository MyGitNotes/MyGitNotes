::::argument-map{title="Bradford：成就的價值" source="Bradford 2013, *Pacific Philosophical Quarterly* 94(2): 204–224"}
- [C] 困難是所有成就價值的來源，所以所有成就都有內在價值｜214–215, 222

:::reason{to="C" id="R1" label="困難有內在價值"}
- [S1] 單純成果觀不成立：困難和成就的價值有關｜210
- [S2] 在 Suits 的烏托邦裡，一切按個鈕就有，我們仍會自己做舒芙蕾、自己蓋房子｜212–213
- _在不必要時仍被選擇的活動，本身值得選擇_｜212
:::

:::reason{to="C" id="R2" label="完善論與意志"}
- [W1] 困難就是需要努力，也就是意志的施展｜219
- [W2] 意志具有特徵性，也值得發展，所以屬於完善論的能力｜216, 221
- [W3] 依完善論，人類特徵能力的卓越施展具有內在價值｜215
:::

:::reason{to="S1" id="R3" label="兩本小說"}
- Smith 與 Jones 寫出同樣好的小說，Jones 還熬過火災、喪失與憂鬱症；Jones 的成就比較好｜208
- 單純成果觀只能否認 Jones 比較好，或否認兩本小說同樣有價值｜209–210
:::

:::reason{to="S1" id="R4" label="聖母峰與直升機"}
- 搭直升機上山頂，不如自己爬上去有價值｜206–207
:::

:::objection{to="R4" id="O1"}

:::

:::objection{to="O1"}
- 即使如此，攀登有價值仍是因為它困難｜207
:::

:::objection{to="R3" id="O2"}

:::

:::objection{to="O2a"}
- 克服逆境本身就是成就，同樣因困難而有價值｜209
:::

:::objection{to="C" id="O3"}

:::objection{to="O3"}
