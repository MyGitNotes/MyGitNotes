::::argument-map{title="Hills：道德證言與道德理解" source="Hills 2009, *Ethics* 120(1): 94–127"}
- [C] 能取得理解時，成熟行動者有很強的理由不服從道德證言，但可以把證言當成建議｜124–126

:::reason{to="C" id="R1"}
- [V] 德性與具道德價值的行動都需要道德理解｜112, 119
- [U] 理解通常無法經由證言取得，要靠練習｜119–121
- [D] 服從讓證言成為與理解競爭的依據；建議則經過檢視，成為自己判斷的材料｜122–123
:::

:::reason{to="V" id="R2" label="無能法官 Claire"}
- Claire 照 Judith 的指引判決都正確，還轉述理由，卻不是好法官｜110
- 她的信念在反事實上依賴 Judith 說了什麼，不依賴理由｜111 註 29
:::

:::reason{to="V" id="R3" label="極端主義者 Ron"}
- Ron 依拉比的證言不殺 Tamara；拉比若給別的理由，他照樣照做｜115–116
- 具道德價值的行動，是出於正確理由而做的正確行動｜113
:::

:::reason{to="U" id="R4"}
- [U1] 理解為什麼 p，不同於知道 p，也不同於知道為什麼 p｜101, 104
- 理解像知道如何：沒有人能靠聽別人描述就學會騎腳踏車｜119
:::

:::reason{to="U1" id="R5" label="Eleanor"}
- Eleanor 從朋友那裡知道吃肉是錯的，也被告知理由，卻判斷不了魚和放養動物的情形｜100
:::

:::reason{to="U1" id="R6" label="史達林教科書"}
- 拿到唯一正確的教科書不算知道，卻能理解史達林為什麼邪惡｜104
:::

:::objection{to="U1" id="O1"}
- [O1a] 理解只是知道為什麼 p，再加上一些額外的命題知識｜103
:::

:::objection{to="O1a"}
- 多知道幾條命題，不保證有能力自己產生新的真信念｜103–104
:::

:::objection{to="R1" id="O2"}
- 對他人而言，重要的只是外在行為｜117
:::

:::objection{to="O2"}
- 從第一人稱看，怎麼作決定也重要；我們也重視被好好對待，不只被正確對待｜117–118
:::

:::objection{to="U" id="O3" label="Zagzebski 的回應"}
- 他人能透過教導、類比與示範幫助我們理解，這樣取得的理解可以像信念一樣得到證成｜[@zagzebski2012epistemic], 176–178
