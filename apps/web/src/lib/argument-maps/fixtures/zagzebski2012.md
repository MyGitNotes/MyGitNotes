::::argument-map{title="Zagzebski：知識權威與取代論題" source="Zagzebski 2012, *Epistemic Authority*, ch. 5" view="standard"}
- [C] 認真的人可以合理地讓權威的信念取代自己其他相關的理由｜105, 107

:::reason{to="C" id="R1"}
- [A] 在某些領域，我認真判斷別人比我自己去想更可能得到真信念｜105
- [J] 這樣的認真判斷證成了權威（JAB 1）｜110
- [P] 權威的信念必須取代我的理由，只把它加權進來並不夠｜114–115
:::

:::reason{to="A" id="R2"}
- 認真的自我信任，使我也必須信任具有我所信任特質的人｜103–105
:::

:::reason{to="P" id="R3" label="Raz 的紀錄論證"}
- 若我先自己判斷，分歧時才給權威加一些份量，在仍與權威相左的案例裡，我的錯誤率依舊高於權威｜114–115
:::

:::objection{to="C" id="O1"}
- 取代要求我們忽略自己的理由，心理上做不到｜113
:::

:::objection{to="O1" label="紅燈"}
- 取代不必忽略理由：因法律而在紅燈前停車，只是讓「法律要求」成為我停車的理由｜113
:::

:::objection{to="P" id="O2" label="整體證據觀"}
- [O2a] 權威的信念只是又一件證據，應該和其他證據相加｜114
:::

:::objection{to="O2a"}
- 理論理由不與第一人稱的審議理由相加｜114–115
:::

:::objection{to="R1" id="O3" label="茄子雨"}
- 醫生要你每小時吃四千顆藥、預報員說明天下茄子雨：荒謬的內容會推翻權威｜116
:::

:::objection{to="O3"}
- 被推翻的是「此人是權威」的判斷，取代論題不受影響｜116–117
:::

:::objection{to="C" id="O4"}
- 自立能贏得更多功勞｜117–118
:::

:::objection{to="O4"}
- 使用可得的最佳策略，包括依賴他人，同樣得到功勞；重視自立甚於真理的人應該直說｜118–119
:::
