#### 示範｜十分鐘的演講

# 輪廓優先的簡報

用一份自擬的文件，測試區塊、投影片與頁的切法

:::summary
〔全場約 10 分鐘〕

這是一份測試用的簡報，內容完全是自擬的。
:::

---

#### 一、規則

## 引言標記開出區塊

每一個以 `####` 開頭的投影片，都開出一個新的區塊，標題就是引言的文字。

:::summary
〔一、約 3 分鐘〕

第一個區塊示範引言標記：標題來自引言，標籤取標題的第一個字。
:::

---

## 兩種步驟

:::build
1. 清單的每一個項目是一步。
2. 表格的每一列也是一步。
3. 沒有 `:::build` 包住的內容**一次全部出現**。
:::

:::summary
步驟有兩種來源：清單的項目與表格的列。沒有包在 build 裡的內容一次全部出現。
:::

---

## 三欄比較

::::grid{cols=3}
:::cell
**文件**

沒有啟動簡報時，整份內容是一篇文章。
:::

:::cell
**輪廓**

每個區塊一格，每張投影片一張縮圖。
:::

:::cell
**講稿**

逐頁的稿子，手機上也能讀。
:::
::::

:::summary
同一份內容有三種檢視：文件、輪廓與講稿。
:::

---

## 數字範例

:::key-numbers{title="這份測試簡報"}
- **10 分鐘**｜預定的演講長度｜分成兩個主要區塊
- 3 頁｜書面的附錄｜不在會上念
:::

:::summary
第一頁用兩個數字說明這份簡報的規模。
:::

::vertical

## 數字範例

|              | 主要區塊 | 附錄     |
| ------------ | -------- | -------- |
| 用途         | 會上講   | 會後讀   |
| 是否計入時間 | **計入** | **不計** |

附錄用標題裡的「附錄」二字標出，不必另外設定。

:::summary
第二頁和第一頁用同一個 `##`，所以同屬一張投影片，是它的第二頁。
:::

---

## 步驟表格

:::build
| 元素 | 一步是什麼 |
| ---- | ---------- |
| 清單 | 一個項目   |
| 表格 | 一列       |
:::

:::summary
這一頁的表格有兩列，各是一步。
:::

::vertical

## 從步驟到頁

::::flow
:::step
**步驟**

按一下，多出一項
:::

:::step
**頁**

步驟用完，換到下一頁
:::

:::step
**投影片**

頁用完，換到下一張
:::
::::

:::summary
這一頁的 `##` 和前一頁不同，所以從這裡起是新的一張投影片。
:::

#### 二、收尾

## 小結

先寫文件，再看輪廓。

:::summary
〔二、約 2 分鐘〕

最後一個主要區塊只有一張投影片。
:::

## 2. 投影片與頁
