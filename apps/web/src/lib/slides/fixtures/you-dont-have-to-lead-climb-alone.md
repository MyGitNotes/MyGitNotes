永恆的自我提問：**我**做得夠好嗎？**我**怎麼做可以讓團更好？

::vertical

::vertical

- **GM** 該是玩家的一員，而且......

# :icon{name="Stethoscope"} 拆解

::vertical

## :icon{name="Mountain"} 領攀的譬喻

**領攀者**承擔著最高的風險與責任。

::vertical

**異化（Alienation）**：

- 當主持是一種服務，就失去了玩家的身份
- 滿足玩家的需求成了 GM 的遊戲主要目的
- 因此，GM 不再是玩家，成了服務者

::vertical

兩個面向導致了異化現象：

- 面向一：GM 功能從遊戲文化演進中獲得擴充
- 面向二：服務心態的互相承認

::vertical

## 面向一：GM 功能的擴充

| 最小遊戲     | 現代遊戲                 |
| :----------- | :----------------------- |
| 裁判         | + 編劇、導演、場景設計師 |
| 執行規則     | + 即興演員、音效師       |
| 裁決行動結果 | + 團體諮商師、活動策劃人 |

::vertical

## 面向二：服務心態的互相承認

1. 如果沒有說好是誰的責任，那就是 GM 的責任。
2. GM 被認為需要對團務好壞負最大責任。
3. GM 被認爲該提供讓團務有趣的核心要素，超出了**最小遊戲**的範圍。
4. GM 的優越感或殉道精神。

::vertical

GM 和 PL 的二元對立：

| 面向     | PL       | GM         |
| :------- | :------- | :--------- |
| 團務貢獻 | 低估自己 | 過度承擔   |
| 遊玩目的 | 獲得樂趣 | 提供好遊戲 |

我們都忽略了：團務是共同的旅程。

::vertical

於是：

- GM 開始認知負荷過載
- GM 過度準備，陷入惡性循環
- PL 和 GM 的共享時刻開始割裂

::vertical

認知負荷理論：

- 工作記憶容量有限（約 4 個 chunk）
- 超過負荷：效率下降、決策品質惡化

:::summary

- [The Magical Mystery Four: How is Working Memory Capacity Limited, and Why?](https://pmc.ncbi.nlm.nih.gov/articles/PMC2864034/)
  :::

::vertical

## 遊戲時的認知負荷

| 類型 | 內容                           |
| :--- | :----------------------------- |
| 內在 | 遊戲機制、角色選項、世界和 NPC |
| 外在 | 潛在社交衝突、後勤工作         |
| 增生 | 敘事、創作、即興、表演         |

:::summary

- [Manage your game's mental load](http://tpsrpg.blogspot.com/2019/11/manage-your-games-mental-load.html)
  :::

::vertical

## 認知負荷與過度準備的惡性循環

- 決策疲勞：固定額度的資源。
- 職業倦怠：漸進的消耗。

:::summary

- [Mental Health and the GM](https://www.campaignmastery.com/blog/mental-health-and-the-gm/)
  :::

::vertical

## 共享時刻的割裂

- 回饋變得迂迴且帶有凝視性。
- 樂趣與成就感被化約成優越感。
- 自我評價會佔用你的主要窗口。

::vertical

不必獨自領攀，讓我們組成冒險小隊。

::vertical

# :icon{name="Users"} 後勤的去中心化

::vertical

## 隱形勞動

- 協調行事曆
- 尋找並預約場地
- 管理群組氛圍
- 撰寫前情提要
- 處理技術問題（VTT、音訊）

:::summary

- [The Logistics of Roleplaying Games](https://www.paulsgameblog.com/2019/09/12/the-logistics-of-roleplaying-games/)
  :::

::vertical

邀請我們：

- 從主持思維，轉向派對思維。
- 解決潛在衝突和劃好界線不是 GM 的責任。
- 從隱形職位到明確分派職位。

::vertical

## 派對委員會

1. 我們一起經營一場有趣的派對，主題是 TRPG
2. 可以考慮分離組織者與 GM 職責（長團）
3. 共同討論建立優良派對環境（零食、道具、VTT 房間佈景等）

::vertical

### 衝突協調

- 建立民主的、和煦的衝突處理機制。
- 使用安全工具與契約工具進行校準（後面會談到）。

:::summary

- [如何進行調查：我們的團務守則](https://trpgtw.blogspot.com/2018/11/blog-post.html)
  :::

::vertical

## 玩家職位系統

[一個 OSG 的範本](https://slyflourish.com/assign_player_roles.html)：

| 職位                 | 核心功能 |
| :------------------- | :------- |
| 記錄員 Scribe        | 官方記錄 |
| 軍需官 Quartermaster | 資源管理 |
| 繪圖師 Cartographer  | 地圖繪製 |
| 召集人 Caller        | 決策統整 |

::vertical

### :icon{name="BookOpen"} 記錄員 Scribe

- 職責：記錄劇情關鍵、NPC 姓名與地點。
- 任務：負責開場的「前情提要」。
- 價值：消除團隊失憶，建立冒險編年史。

::vertical

### :icon{name="Backpack"} 軍需官 Quartermaster

- 職責：管理隊伍公共財（金幣、藥水）。
- 任務：維護戰利品清單，確保分配透明。
- 價值：避免關鍵道具被遺忘在背包深處。

::vertical

### :icon{name="Map"} 繪圖師 Cartographer

- 職責：將口述場景轉化為視覺結構。
- 任務：繪製路徑，標記已探索區與未知缺口。
- 價值：建立空間感。不用畫得漂亮，結構清楚即可。

::vertical

### :icon{name="Megaphone"} 召集人 Caller

- 職責：統合意見，向 GM 宣告「最終行動方案」。
- 任務：主持投票或協調，避免七嘴八舌。
- 價值：擔任協調者（非獨裁者），維持遊戲節奏。

# :icon{name="MessageSquare"} 敘事權的重定位

::vertical

## 敘事權的光譜

| 分類     | GM 角色        | PL 角色        |
| :------- | :------------- | :------------- |
| 傳統     | 裁判、模擬引擎 | 探索者、解謎者 |
| 新傳統   | 導演、編劇     | 角色扮演者     |
| 故事遊戲 | 主持人、引導者 | 共同作者       |
| OSR      | 沙盒維運者     | 冒險者         |
| 無 GM    | N/A            | 平等敘事者     |

::vertical

- 敘事權不是全有全無。
- 妥當配置敘事權，來讓我們恰當對敘事共同負責。
- 敘事權的共同負責，是為了讓我們**共同創作**。

::vertical

## 什麼是妥當配置？

- 避免 GM 的主敘事軸失控
- 避免遊戲成就的廉價化
- 避免遊戲的細節、氛圍與成就的對齊失敗

::vertical

## 共同創作的工具

- 主動式玩家
- PbtA 哲學
- 授權機制

::vertical

### 主動式玩家：編劇室思維

- 導演：主動的戲劇性敘事（展現場景、體現氛圍、貼合弧線）而非被動描述
- 編劇：在轉場時，主動提出場景需求
- 觀眾：在場，觀賞並享受其他人的扮演

::vertical

### PbtA 哲學：你不用自己做決定

- 問探索性問題：校準角色並協助玩家發展角色故事弧，「你覺得，失去什麼會讓他感到徹底哀傷？」
- 向玩家詢問故事發展建議或細節：分享你的創作樂趣
- 下放描述權：讓玩家描述他的成功時刻、讓參與者建議他的失敗時刻

::vertical

### 授權機制

參考一些敘事授權機制：

- 情節點（DMG 可選規則）：讓 PL 短暫取得 GM 部分敘事權（以資源稀缺性平衡）
- 命運點（Fate 基本機制）：讓 PL 提出 GM 無法拒絕的發展和細節描述（以犧牲平衡）
- 回憶機制（BitD、CotM）：讓 PL 補充背景或是幕外的過往事件（以擲骰平衡）

# :icon{name="Map"} 經營遊戲場域

::vertical

**IKEA 效應**：人們對於自己勞動組裝的產品評價更高。

> 共同建構的世界，玩家自然有保護它的動機。

::vertical

## 遊戲場域

- 摸索適合我們的框架和默契。
- 透過工具和儀式性活動，建立對遊戲場域的共同認同。
- 透過契約和對話，建立對遊戲場域的共同責任。
- 建立遊戲場域不是一次性的，它需要定期回顧、迭代、成長、演進（因此也需要校準工具）。

::vertical

在第零次聚會中考慮使用：

1. 從對話建立 CATS 社交契約
2. 工作坊
3. 微型遊戲

::vertical

## CATS 社交契約

從對話建立：

- :icon{name="Lightbulb"} **C**oncept（概念）：「太空西部片」
- :icon{name="Target"} **A**im（目標）：為了生存？成為英雄？
- :icon{name="Palette"} **T**one（基調）：嚴肅、詼諧、恐怖？
- :icon{name="FileText"} **S**ubject Matter（題材）：主題與安全邊界

:::summary

- [The CATS Method](https://proleary.com/games/the-cats-method/)
- [CATS - Concept Aim Tone Subjectmatter](https://www.scribd.com/document/510158843/CATS-Concept-Aim-Tone-Subjectmatter)
  :::

::vertical

## 工作坊

透過一系列討論來讓玩家投入創作：

1. 討論世界當前的狀態和議題
2. 透過玩家角色，創作與玩家關聯的組織、人物、地點
3. 建立、探索玩家角色間的關係和基本認識
4. 設計玩家之間可能的未來衝突和平衡如何維繫
5. 可以準備一些小紙卡，記錄你們的創作

:::summary

- [命運核心版：創造遊戲](https://sites.google.com/site/faterpg/core/gamecreation)
- 怪物心：我們的小鎮
  :::

::vertical

## 微型遊戲

建立世界架構的遊戲面向：

1. 我們的城市（小鎮、村莊、國家）：[平靜之年 The Quiet Year](https://www.drivethrurpg.com/product/110152/The-Quiet-Year)
2. 歷史：[顯微鏡 Microscope](https://www.drivethrurpg.com/product/91183/Microscope)
3. 政治：[王國 Kingdom (2nd Edition)](https://www.drivethrurpg.com/product/369018/Kingdom-2nd-Edition)

::vertical

### 平靜之年

- 使用一副撲克牌，每一張牌代表一週並對應特定事件，玩家根據事件在白紙上共同繪製地圖變化。
- 結局必然到來：當抽到「寒霜牧人」卡片時，遊戲立即結束。

::vertical

### 顯微鏡

- 先建立調色盤，討論可以有什麼、不能有什麼。
- 玩家可以隨意跳躍聚焦，先創造「結局」，再回頭補完「起源」，或插入中間的任何片段（選擇不同規模當作焦點）。

::vertical

### 王國

- 玩家交替扮演三種職責：權力（做決策）、觀點（預測後果）、試金石（反映民意）。
- 由一連串的「重大決策」推動。探討當組織面臨危機時，不同立場如何影響王國的命運。

# :icon{name="Shield"} 校準工具

::vertical

校準工具不是為了「保護脆弱」或「審查內容」，而是校準我們對遊戲的期待。

安全是**所有人**的責任，校準的目的在於未來的相處與溝通。

::vertical

## 安全性與校準工具

1. X 卡
2. 開門政策 Open Door Policy
3. 星星與願望 Stars and Wishes

::vertical

### X 卡

- 以知情合意、輕鬆地使用作為核心的工具。
- 有些事情不談論較為安全。

:::summary

- [X 卡中文翻譯](https://docs.google.com/document/d/1w0lJuThtmem2ExlwNeQt05UZxHEAQFT81Mx31zlichQ/edit?tab=t.0)
  :::

::vertical

### Open Door Policy

- 明確告知任何人都可以因任何理由暫時離席或退出遊戲，且不會受到評判。
- 所有人都有安全出口。
- 退團已經很需要勇氣，不需設下更多情感阻礙。

::vertical

### 星星與願望

每次聚會結束後，邀請每個人分享：

- **:icon{name="Star"} 星星**：一個本場遊戲中最喜歡的時刻，可以是其他玩家的扮演還是 GM 的某個設計。
- **:icon{name="Wand2"} 願望**：一個希望在未來團務中看到的元素。

:::summary

- [Stars And Wishes: Feedback System Explained](https://www.ttrpg-games.com/blog/stars-and-wishes-feedback-system-explained/)
- [Stars and Wishes](https://www.gauntlet-rpg.com/blog/stars-and-wishes)
- [What Are Stars and Wishes?](https://ttrpguniversity.com/stars-wishes/)
  :::

## 如果你是 PL

- 團務不順，別急著歸咎責任。
- 開始想想，我可以對團務有怎樣的貢獻。
- 我樂意承擔怎樣的職位？
- 開始做一個主動式玩家。

::vertical

## 如果你是 GM

- 不要放大失敗，輕鬆地收集回饋和成長。
- 帶著團員一起成長，而不是只幫他們領路。
- 將一些職能分出來，做好專注管理。
- 鼓勵玩家的主動性。

::vertical

## 不管你是誰

- 將團員當成合作夥伴。
- 將團務當成旅程，共享美妙時刻。
- 讓優越感和框架鬆動一下。
- 對自己溫柔一點，你做得很好。
