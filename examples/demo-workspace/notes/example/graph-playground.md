# Whiteboard Playground

Start here. The Whiteboard Playground compilation lays these notes out on a whiteboard, in sections, with free text and labelled arrows between the cards. Open it from the Whiteboards tab.

- [Riverside Reading](river-reading.md): a note with an image.
- [Evening Ideas](evening-ideas.md): another image and links back to related notes.
- [Music and Resources](music-resources.md): YouTube and image previews.
- [Dated Tasks](todo-demo.md): tasks you can check off in the to-do tool.

Try moving a card into another section, drawing an arrow from one card to another and naming it, or adding a note from the Note library. Links written inside these notes show on the board as dashed lines.
